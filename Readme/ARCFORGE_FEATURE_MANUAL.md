# ARCFORGE 플랫폼 시스템 기능 매뉴얼
**플랫폼 명칭**: ARCFORGE Platform (Enterprise SCM)  
**포함 컴포넌트**: 통합 인증 센터, 동적 메뉴 빌더, ARC-WIZARD 바이브 코딩 엔진  
**적용 환경**: 로컬 개발망 및 클라우드/사내 분산 독립 서버

---

## 1. 시스템 로그인 가이드

ARCFORGE 플랫폼은 강력한 보안 정책과 사용자 편의성을 동시에 제공하는 모던 2열 분할형 통합 인증 센터를 제공합니다.

### 1-1. 로그인 화면 접속
* **접속 경로**: `http://{서버IP 또는 도메인}:{포트}/auth/login`
  * 로컬 개발 환경: `http://localhost:3003/auth/login`
  * 원격 배포 서버: `http://45.113.51.188:3005/auth/login`

### 1-2. 4대 권한 탭 원클릭 로그인
로그인 화면 상단에서 접속하고자 하는 기관/업체 카드를 클릭하면 해당 역할에 맞는 최적화된 초기 계정 정보가 자동으로 채워집니다:

| 탭 선택 카드 | 소속 및 권한 | 기본 로그인 ID | 초기 표준 비밀번호 | 로그인 후 이동 페이지 |
| :--- | :--- | :--- | :--- | :--- |
| **MPSI 본사** | `MPSI` (총괄 관제) | `mpsi` | `Mpsi2026!@` | `/portal/project` (프로젝트 관리대장) |
| **시스템 관리국** | `ADMIN` (최고 관리자) | `admin` | `Mpsi2026!@` | `/portal/project` (통합 관리자 모드) |
| **금형 협력사** | `VENDOR_MOLD` (금형 제작) | `woosung` | `Mpsi2026!@` | `/portal/vendor-portal/mold/projects` |
| **양산 협력사** | `VENDOR_MASS` (사출 양산) | `newmold` | `Mpsi2026!@` | `/portal/vendor-portal/mass/projects` |

### 1-3. 계정 보안 및 URL 접근 제어 정책
1. **단방향 암호화 해싱**:
   * 비밀번호는 SHA-256 표준 단방향 해시로 암호화되어 안전하게 보관됩니다.
   * `http://` 공인 IP 접속 환경에서도 표준 웹 크립토 폴리필이 동작하여 오동작 없는 안전한 인증을 지원합니다.
2. **비인가 URL 다이렉트 접근 차단 (Role Guard)**:
   * 로그인을 거치지 않고 기본 URL(`/`)이나 서브 화면으로 직접 접속하면 자동으로 `/auth/login`으로 강제 리다이렉트됩니다.
   * 협력사(우성정공/뉴몰드) 계정으로 시스템 최고관리자 전용 화면(`/portal/admin/...`) URL을 직접 브라우저 주소창에 입력하여 진입할 경우 **`403 접근 권한 없음`** 안내 화면이 출력되며 불법적인 화면 열람이 원천 차단됩니다.

## 2. 메인 플랫폼 주요 편의 기능

### 2-1. 소속사 맞춤형 브랜딩 표기
좌측 사이드바 상단에는 로그인한 사용자의 회사명에 따라 고유한 플랫폼 타이틀이 실시간 렌더링됩니다:
* MPSI 본사 로그인 시: **`MPSI ARCFORGE`**
* 우성정공 로그인 시: **`우성정공(주) ARCFORGE`**
* 뉴몰드 로그인 시: **`(주)뉴몰드 ARCFORGE`**

### 2-2. 실시간 AI Token Usage 관제 배지
시스템 관리자(`ADMIN`) 화면의 최상단 헤더 우측에는 ARC-WIZARD AI 엔진의 실시간 토큰 사용 현황이 배지로 상시 표시됩니다:
* **표기 형식**: `Usage: {당일 사용 토큰수} Tok | 잔여 {잔여율}% ({잔여 토큰수}k)`
* **시각화 프로그레스 바**: 일일 무료 쿼터 한도(100만 토큰) 대비 잔여량을 실시간 게이지 바로 직관적으로 모니터링할 수 있습니다.

### 2-3. 다이내믹 메뉴 에디트 모드 (시스템 최고관리자 전용)
시스템 최고 관리자는 코드를 수정하지 않고 브라우저 상에서 사이드바 메뉴 트리를 실시간으로 추가, 수정, 삭제(CRUD)할 수 있습니다:

1. **에디트 모드 활성화**:
   * 사이드바 헤더의 **`[✏️ 메뉴 편집]`** 버튼을 클릭하여 편집 모드를 켭니다.
2. **대분류 섹션 추가**:
   * `[+ 대분류 추가]`를 클릭하여 신규 대분류 섹션을 생성합니다.
3. **폴더형 그룹메뉴 추가**:
   * 각 섹션의 `[+ 그룹]` 버튼을 클릭하여 하위 폴더 메뉴를 생성합니다.
4. **단위 화면(서브메뉴) 추가**:
   * 각 그룹 또는 섹션 내에서 `[+ 메뉴 추가]`를 클릭하여 메뉴명, 접속 라우트 URL, 그리고 **열람 권한(ADMIN, MPSI, MOLD, MASS)**을 체크하여 실시간 저장합니다.
5. **동기화**:
   * 최고관리자 화면에서 수정된 메뉴 구조는 즉시 `src/config/menu-config.json`에 저장되어 타 권한(우성정공, 뉴몰드) 사용자 화면에도 권한별로 즉시 반영됩니다.

## 3. ARC-WIZARD 바이브 코딩 상세 가이드

ARC-WIZARD는 화면을 보면서 실시간으로 소스 코드(`.tsx`)와 UI 레이아웃을 대화형으로 수정하는 지능형 온스크린 에디터입니다.

### 3-1. 아크위저드 실행 및 윈도우 조작
1. **위젯 열기**:
   * 화면 우측 하단의 파란색 **`[ARC-WIZARD]`** 플로팅 아이콘을 클릭합니다.
2. **윈도우 창 제어**:
   * 헤더의 컨트롤 버튼을 통해 창 최소화(`-`), 창 크기 확대/축소(`□`), 닫기(`✕`)를 자유롭게 조작할 수 있습니다.
   * 작업창을 닫아도 기존 대화 이력과 작업 상태는 안전하게 유지됩니다.

---

### 3-2. 핵심 기능 1: 🎯 요소 선택해서 문구 바꾸기 (Element Picker)
화면에 보이는 텍스트를 마우스 클릭 한 번으로 소스 코드에서 찾아내어 바꿀 수 있습니다:

1. 아크위저드 하단의 **`[🎯 요소 선택해서 문구 바꾸기]`** 버튼을 누릅니다.
2. 화면에 마우스를 올리면 텍스트 요소 주위로 **형광 녹색 박스**가 실시간으로 하이라이트됩니다.
3. 바꾸고자 하는 글자(예: `"구분 필터"`)를 마우스로 직접 클릭합니다.
4. 아크위저드 창에 해당 문구가 자동 입력되며, 변경할 새 문구를 묻는 입력창이 열립니다.
5. 새 문구(예: `"검색 필터"`)를 입력하고 확인을 누르면 **실제 소스 코드의 해당 줄이 치환**되고 백업 파일이 생성됩니다.

---

### 3-3. 핵심 기능 2: 자연어 대화형 지시 (Vibe Coding)
명령창에 일상 대화처럼 명령어를 입력하여 화면을 즉시 변경할 수 있습니다:

* **문구 변경**:
  > `"조회 기간"을 "기간"으로 바꿔줘`  
  > `"수주일"을 "발주일"로 변경해줘`
* **테이블 컬럼 제어**:
  > `"고객사" 컬럼 숨겨줘`  
  > `"진행상태" 컬럼 다시 보여줘`  
  > `현재 숨김 처리된 컬럼 보여줘`
* **최근 변경 이력 확인**:
  > `변경 이력 보여줘`
* **이전 상태로 되돌리기 (Undo)**:
  > `되돌려줘`  
  > `원복해줘`

---

### 3-4. 핵심 기능 3: 변경 이력 및 원클릭 롤백 (Undo System)
* 아크위저드가 소스 코드를 수정할 때마다 원본 파일이 프로젝트 내 **`.arc-wizard/backups/`** 디렉토리에 타임스탬프와 함께 자동 백업됩니다.
* 마음에 들지 않거나 오작동 시 대화창에 **`"되돌려줘"`**를 입력하거나 하단의 **`[↺ 최근 변경 되돌리기]`** 버튼을 누르면 직전 상태로 1초 만에 완벽하게 롤백됩니다.

---

### 3-5. 핵심 기능 4: AI 엔진 설정 및 보안 정책
헤더의 톱니바퀴 아이콘(`⚙️`)을 클릭하여 아크위저드의 AI 모델과 연결 설정을 관리할 수 있습니다:

1. **지원 모델**:
   * **`gemini-3.8-flash` (기본 권장)**: 빠르고 비용 효율적이며 대규모 코드 분석 지원
   * `gemini-3.5-flash-lite`: 경량/초고속 모델
   * `gpt-4o`: OpenAI 호환 커스텀 모델
2. **API Key 보안 마스킹 (보안 강화)**:
   * API 키는 브라우저 화면이나 응답 데이터에 절대 노출되지 않으며, **`● 보안 키 적용중 (비공개)`** 배지로만 안전하게 표기됩니다.
3. **연결 테스트**:
   * **`[연결 테스트]`** 버튼을 누르면 현재 설정된 모델과 키가 Google API 서버와 정상 통신하는지 즉시 점검할 수 있습니다.

## 4. 서버 배포 및 운영 가이드

### 4-1. 개발 모드 vs 프로덕션 빌드 운영 가이드
* **개발 모드 (`npm run dev`) [권장]**:
  * 아크위저드로 화면 문구나 컴포넌트를 변경하면 **브라우저에 0.5초 만에 실시간 반영(Fast Refresh)**됩니다.
  * 내부 기획/수정/테스트 단계에서는 PM2에 개발 모드로 등록하여 운영하는 것을 적극 권장합니다:
    ```bash
    pm2 delete mpsi-app
    pm2 start npm --name "mpsi-app" -- run dev -- -p 3005
    pm2 save
    ```
* **프로덕션 빌드 모드 (`npm run build` + `start`)**:
  * 완벽한 배포 및 운영 단계에서 사용합니다:
    ```bash
    npm run build
    pm2 restart mpsi-app
    ```

### 4-2. PM2 유용한 관리 명령어 모음
```bash
# 서비스 상태 확인
pm2 status

# 실시간 서비스 로그 모니터링
pm2 logs mpsi-app

# 서비스 재시작
pm2 restart mpsi-app

# 서비스 중지 및 삭제
pm2 stop mpsi-app
pm2 delete mpsi-app
```
