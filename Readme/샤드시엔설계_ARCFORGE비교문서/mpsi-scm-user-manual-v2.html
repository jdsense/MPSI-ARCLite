MPSI SCM 포털 화면 명세 매뉴얼

화면별 구성, 입력 항목, 선택 옵션, 조건에 따라 달라지는 동작과 스크린샷을 정리했습니다. 본사 통합 허브 화면 기준입니다.

이 문서를 읽는 방법

이 문서는 MPSI SCM 포털의 화면을 변환 AI가 같은 구조로 다시 만들 수 있도록 화면별 구성, 입력 항목, 조건에 따라 달라지는 동작을 정리한 명세형 매뉴얼입니다. 사람이 읽는 사용 설명도 함께 담았습니다.

근거 표시

동작 설명 옆에 근거를 표시했습니다.

관찰
화면을 직접 조작해서 확인했습니다. 선택 상자를 바꾸거나 탭을 눌러 결과를 봤습니다.
안내문
화면에 적혀 있는 안내 문구를 옮겼습니다. 실제 동작은 확인하지 못했습니다.
미검증
버튼 이름과 위치만 확인했고 누르지 않았습니다. 저장·승인·발송·다운로드·업로드처럼 데이터를 바꾸거나 파일을 주고받는 버튼이 여기에 해당합니다.

기준 환경

  • 접속 주소: http://localhost:3000 (개발 환경). 로그인 없이 바로 열렸습니다.
  • 허브: MPSI 본사 총괄 관제. 협력사 허브 화면은 확인하지 않았습니다.
  • 화면 폭: 약 1568px 데스크톱. 모바일 화면은 확인하지 않았습니다.
  • 화면의 업체명·번호·금액은 모두 예시 데이터입니다. 이 문서의 값은 “예시 값”으로 읽으세요.
  • 담당자 이름과 연락처는 문서에서 뺐습니다.

스크린샷 준비

이 파일과 같은 폴더에 있는 setup-screenshots.ps1을 실행하면 캡처 파일이 의미 있는 이름으로 screenshots/ 폴더에 복사됩니다. 원본은 지우지 않습니다. 파일을 포토샵으로 고칠 때는 같은 이름으로 저장하세요.

powershell -ExecutionPolicy Bypass -File .\setup-screenshots.ps1
